# 抖音下载器

一个只管「存下来」的小工具：粘贴抖音的分享文字，解析出无水印视频，存到本地。

界面风格照 [Kazumi](https://github.com/Predidit/Kazumi) 的 Material 3 深色主题来做（绿 seed 色、Tonal Card、24px 圆角、几乎不用毛玻璃）。

## 功能

- **单条下载**：粘贴分享链接或整段分享文字，自动提取链接
- **无水印**：走 `play_addr` 而非 `playwm`，拿到的就是原始画质
- **断点续传**：`.part` 临时文件 + Range 请求，中断后重来不从头下
- **重名不覆盖**：同名文件自动加 ` (2)`
- **首次引导**：4 步引导（使用约定 → 保存位置 → 下载偏好 → 就绪），之后可在设置里重看
- **个性化**：深色 / 浅色 / 跟随系统三档外观，6 个预设主题色 + 任意自定义颜色，系统/等宽字体切换（浅色模式下主色会自动压暗以保持可读对比度）
- **检查更新**：读 GitHub Releases，资产下载走镜像前缀（默认 `gh-proxy.com`），绕开 github.com 直连超时

## 用法

1. 抖音里「分享 → 复制链接」
2. 打开本工具，粘贴（启动时若剪贴板里已有链接会自动填进去）
3. 点「解析」，确认封面和标题，点「下载视频」

默认存到 `下载\抖音下载器`，可在设置里改。

## 技术说明

- Electron 33 + 原生 HTML/CSS/JS，无构建步骤
- 解析：隐藏 `BrowserWindow` 加载 `douyin.com/video/{id}`，靠 preload 注入劫持 `fetch`/`XHR` 抓 `aweme/detail` 响应；若页面自身不发请求，则由页面上下文主动探针请求（带 cookie）。纯 HTTP 请求会被字节的 `__ac_nonce` / Argus 挡掉，所以必须借浏览器环境。
- 下载：`https.get` + `Referer: https://www.douyin.com/`（不带 Referer 会 403）
- 打包：electron-builder，MSI perMachine

## 已知限制

- 只支持单条，不做主页批量
- 不登录，因此不保证所有视频都能拿到（部分限制级/直播回放拿不到）
- 首次解析可能触发一次人机验证，届时会自动把隐藏窗口显示出来，点一下即可，之后 cookie 会记住
